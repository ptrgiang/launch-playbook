# Draft taglines

## Steps

1. Read `<launch-folder>/launch.json` — name, one_liner, what_it_does, who_its_for, pricing.
2. Read `docs/assets.md` for formulas and constraints.
3. Draft **at least 8 variants**, covering each formula at least once: outcome-for-audience, verb-first, contrast, familiar-reframe, number-led.
4. Enforce ≤55 characters. No jargon, no "revolutionary/all-in-one/supercharge", product name may not explain itself.
5. Write `copy/taglines.md`: fill the drafts table (chars, formula), recommend a winner with reasoning, list rejected variants and why.
6. Report the winner and the 2 runners-up.

## Rules

- A tagline fails if a stranger can't say what the product does. Judge your own drafts by that test and say which pass.
- Prefer concrete nouns and verbs over adjectives.
- If `who_its_for` is fuzzy, the tagline will be too — flag it before drafting.
