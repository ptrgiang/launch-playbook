# launch-playbook

The open playbook for shipping a product launch — written so your coding agent can run it.

Clone it, describe your product in `launch.json`, and let your agent draft the tagline, the maker comment, the gallery plan, and every cross-post — using the same checklists and rules the best launches follow.

Built for Claude Code, Codex, Cursor, Gemini CLI, and anything else that reads files.

## Quickstart

```bash
git clone https://github.com/<you>/launch-playbook.git
cd launch-playbook

# 1. Copy the workspace template for your launch
cp -r templates/ launch-myapp/

# 2. Describe your product
$EDITOR launch-myapp/launch.json

# 3. Hand it to your agent
claude   # then: "run /launch-checklist for launch-myapp"
```

Your agent reads `docs/`, writes into your launch folder, and you review file diffs. Everything is Markdown and JSON — nothing is locked in.

## What's inside

| Path | What it is |
|---|---|
| `docs/` | The playbook: PH mechanics, asset anatomy, channel rules, launch timeline, failure modes, postmortem |
| `templates/` | Every file a launch folder is made of — copy, schemas, cross-posts |
| `skills/` | Agent skills that run the playbook (`/launch-checklist`, `/draft-taglines`, …) |
| `data/` | Corpus of analyzed top launches + launch schema. PR your postmortem back. |

## The launch folder

```
launch-myapp/
├── launch.json            # product, audience, target date
├── checklist.json         # generated by /launch-checklist
├── copy/                  # taglines, description, maker comment, faq
│   └── crossposts/        # x-thread, linkedin, show-hn, reddit/<sub>
├── assets/                # gallery (1270×760), thumbnail, demo
├── research/              # category analysis, competitors, comments inbox
├── schedule.json
└── postmortem.md
```

The folder format is the API. Any agent that can read and write files can run your launch.

## Skills

| Skill | Runs |
|---|---|
| `/launch-checklist` | Generates your T-14 → T+7 checklist from `launch.json` |
| `/draft-taglines` | Writes tagline variants into `copy/taglines.md` |
| `/write-maker-comment` | Drafts your first comment |
| `/analyze-category` | Researches top launches in your category |
| `/draft-crossposts` | Writes per-channel posts, respecting each channel's rules |
| `/review-launch-page` | Audits a drafted launch against the playbook |
| `/suggest-replies` | Drafts comment replies in your voice on launch day |
| `/postmortem` | Compiles metrics into `postmortem.md` |

## Rules that matter most

1. Never ask for upvotes. "Check it out" is allowed; "upvote me" gets you flagged.
2. Reply to every comment, fast, with substance. Comment velocity outranks raw votes.
3. Launch at 00:01 PST on a Tuesday–Thursday. Own the whole day.
4. Your first gallery image is your real tagline. Make it carry the pitch.
