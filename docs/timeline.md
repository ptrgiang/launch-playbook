# Launch timeline

T-14 days to T+7. Checklist generated per-launch by `/launch-checklist` into `checklist.json`.

## T-14 to T-10 — position

- [ ] Pick launch date: Tue/Wed/Thu, no conflicts (holidays, tech events, mega-launches)
- [ ] Audit the landing page: <3s mobile load, CTA above fold, no signup wall before value
- [ ] Warm up your PH account: comment on other launches (featured odds care about maker history)
- [ ] Draft `launch.json`: product, audience, category, persona, voice notes

## T-10 to T-7 — assets

- [ ] `/draft-taglines` → pick winner with a stranger test
- [ ] Description drafted (`copy/description.md`)
- [ ] Maker comment drafted (`copy/maker-comment.md`)
- [ ] Screenshots captured → gallery planned (hook → product → payoff → proof → CTA)
- [ ] Demo video scripted and recorded (30–60s, muted-viewable)
- [ ] Thumbnail made (first GIF frame reads at 240px)

## T-7 to T-3 — amplify prep

- [ ] `/draft-crossposts` → x-thread, linkedin, show-hn, reddit per-sub
- [ ] Subreddit rules re-checked for every target sub
- [ ] Email/notify list blast drafted (send T0 07:00–08:00 PST)
- [ ] Supporters list: who you'll tell — with "check it out" phrasing, not vote asks
- [ ] PH offer/coupon code created if you have pricing

## T-3 to T-1 — dry run

- [ ] Full page assembled as draft; every image, link, topic verified
- [ ] `/review-launch-page` audit passes
- [ ] FAQ answers pre-drafted (`copy/faq.md`) — launch-day replies get faster
- [ ] Load test the landing page; analytics + UTM verified
- [ ] Sleep plan decided: who covers 00:01–04:00 PST, who covers EU morning
- [ ] Go to bed early. Launch day is a marathon.

## Launch day — hour by hour (PST)

| Time | Do |
|---|---|
| 00:01 | Publish. Maker comment within 5 minutes. |
| 00:15 | First supporters wave; reply to every comment <30 min |
| 04:00 | Checkpoint: rank, velocity, who's climbing. Adjust energy accordingly. |
| 07:00–09:00 | Cross-post wave: X thread (pin it), LinkedIn post |
| 09:00–11:00 | Reddit posts per-sub; email blast |
| 11:00–17:00 | Reply duty. Milestone QTs allowed. Watch board hourly. |
| 17:00–23:59 | Final push: reply everything, thank commenters, hold rank |

## T+1

- [ ] Show HN goes live (own day, own copy)
- [ ] Badge embed on landing page (if top 5)
- [ ] Thank-you posts; reply to stragglers
- [ ] Capture metrics NOW: rank, votes, comments, referral traffic, signups, conversion

## T+2 to T+7

- [ ] `/postmortem` → `postmortem.md` while numbers are fresh
- [ ] Secondary directories (BetaList, Uneed, AlternativeTo, SaaSHub)
- [ ] Indie Hackers retro post with real numbers
- [ ] Repurpose launch assets into evergreen content
- [ ] PR your postmortem back into this repo's `data/` — feed the corpus
